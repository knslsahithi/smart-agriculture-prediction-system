ABOUT THE PROJECT

Smart Agriculture Prediction System

A machine learning based crop recommendation system designed to support data-driven agricultural decisions.

🎯

Objective

Recommend a suitable crop based on soil nutrient values and environmental conditions.

📊

Dataset

The primary training dataset contains crop records with N, P, K, temperature, humidity, pH and rainfall.

🤖

Machine Learning

Decision Tree, Random Forest, KNN and SVM were evaluated. Random Forest achieved the highest measured test accuracy.

💻

Technology

Python, Pandas, Scikit-learn, Flask, HTML, CSS, JavaScript and SQLite.
